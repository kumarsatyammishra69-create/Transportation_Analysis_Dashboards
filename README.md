# Power BI Transportation & Transit Analytics Dashboards

This repository contains two interactive **Power BI dashboards** created to analyze transportation, logistics, and public transit data.

The dashboards provide insights into shipments, transportation modes, carriers, revenue, operating costs, profit, passengers, and yearly trends using interactive visuals and filters.

---

##  Dashboards Included

### 1.  Transportation & Logistics Dashboard

This dashboard focuses on shipment and logistics performance.

### Key Insights:
- Total Shipment Cost
- Average Distance
- Total Profit
- Total Revenue
- Shipment Status
- Shipment by Transportation Mode
- Shipments by Carrier
- Shipment Origin Analysis
- Delivered, Delayed, In Transit and Cancelled shipments

### Filters:
- Year
- Month
- Product Type
- Status

### Transportation Modes:
- Road
- Sea
- Rail
- Air

---

### 2.  Public Transit Dashboard

This dashboard analyzes public transportation performance, passengers, revenue, operating costs, and profit.

### Key Insights:
- Total Trips
- Total Revenue
- Total Operating Cost
- Total Profit
- Profit Margin
- Trips by Passenger Type
- Revenue by Passenger Type
- Operating Cost vs Revenue by Vehicle Type
- Profit Margin by Year
- Profit by Vehicle Type and Location

### Filters:
- Year
- Month
- City
- Vehicle Type
- Passenger Type

### Passenger Types:
- Regular
- Student
- Senior Citizen
- Tourist

### Vehicle Types:
- Bus
- Ferry
- Light Rail
- Metro
- Tram
